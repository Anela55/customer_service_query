
# Customer Service Data Query

## Project Overview

Customer Service Data Query is a web-based application
developed to demonstrate how customer service requests
can be recorded, searched, monitored and managed.

The application uses HTML, CSS and JavaScript.

## Objectives

- Manage customer service requests.
- Record customer names and email addresses.
- Assign priorities to support requests.
- Search for existing requests.
- Update request statuses.
- Display dashboard statistics.
- Export request records to CSV.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- CSV Export

## Main Features

### Dashboard
Displays customer counts and request statistics.

### Customer Requests
Allows users to add new requests with customer details,
issue descriptions and priority levels.

### Search
Supports searching by customer name, email, request ID,
issue description, priority and status.

### Status Management
Users can resolve requests and reopen resolved requests.

### CSV Export
Allows filtered request records to be exported for reporting.

### Data Validation
Checks required fields, email format and duplicate
unresolved requests.

## Project Files

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a modern web browser.
3. Add a customer request.
4. Search, update or export the demonstration records.

No package installation is required for this front-end version.

## Data Storage

This demonstration uses browser Local Storage.

Data is stored in the current browser and does not
automatically synchronize across devices or users.

Sample records are synthetic demonstration data.

Do not enter confidential or real customer information.

## Limitations

This version does not yet include:

- A production database.
- User authentication.
- Server-side authorization.
- A shared customer support system.
- AI-powered natural-language queries.
- Production deployment.

These features require additional backend services
and security configuration.
